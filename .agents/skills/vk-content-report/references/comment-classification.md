# Классификация комментариев (шаг 4)

Применяется только к комментариям, связанным с post_id из датасета. Результат —
`comment-signals.json` (структура: `comment-signals-schema.md`).

## Категории (предварительные, лексические)

| Категория | Признак | Как используется в отчёте |
|---|---|---|
| question | есть «?» | сигнал вовлечения |
| product_interest_question | вопрос о цене, записи, материале | интерес к продукту |
| purchase_motive | готовность платить, «сколько стоит» | мотив покупки |
| objection_or_doubt | «но», «не согласен», «проблема в том» | возражение |
| problem_statement | «не могу», «нет времени», «не получается» | формулировка боли |
| desire | «хочу», «надо бы», «жду продолжения» | намерение |
| personal_story_resonance | «у меня так же», «сталкивался» | узнавание |
| safety_concern | безопасность, ответственность за людей | тревога |
| positive_reaction | спасибо, классно, согласие | поддержка темы |
| negative_reaction | бред, пирамида, «листаем дальше» | отторжение |
| comment_on_topic_no_clear_signal | по теме, без выраженного сигнала | фон |
| empty_or_emoji | пусто или только эмодзи | не считается сигналом |
| spam_ad | рекламный шаблон | исключается из подсчётов |

## Правила

1. Одна запись может получить несколько категорий; приоритета нет — категории перечисляются.
2. Спам-шаблон: один и тот же текст (после нормализации пробелов и регистра) на 5+ постах.
   Такие комментарии помечаются `is_spam_template: true` и исключаются из сигнальных сводок.
3. Комментарии конкурентов не относятся к аудитории текущего бизнеса: в выводах их можно
   использовать только как «реакцию читателей сообщества X».
4. Единичный комментарий — это одна реплика, а не тренд. Вывод допускается, если категорию
   подтверждают минимум 2 разных комментария или 1 комментарий + поведение метрик того же поста.
5. Классификация скрипта — предварительная. Окончательную интерпретацию делает модель,
   цитируя оригинал дословно (см. `quotes-and-links.md`).
