# Требования к объёму отчёта (шаг 8)

Проверяет `validate_report.py` (exit code 2 при нарушении).

| Метрика | Норма |
|---|---|
| Объём текста (слова, без HTML-разметки) | 900–1500 слов |
| Число предложений | не более 60 |
| Длина предложения | не более 30 слов |
| Строк в таблице масштаба | не более 8 |
| Блоков смыстной вертикали | 10 обязательных + приложения опционально |
| Доказательных ссылок | ≥1 на каждый сигнал и вывод |

Если текст не умещается: сокращается пересказ, остаются числа, цитаты и ссылки.
Дальше 1500 слов отчёт не растёт — лишнее удаляется, а не переносится в приложение.
