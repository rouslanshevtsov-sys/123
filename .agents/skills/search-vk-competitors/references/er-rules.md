# Правила расчёта ER

## Временное окно
Единое для всех сообществ: последние **31 × 24 часов** от момента сбора
(`window_start = now − 744 ч`). Окно фиксируется в паспорте запуска.

## Отбор публикаций
- Источник: `wall.get`, `owner_id = -group_id`, `filter=owner`, `count=100`,
  пагинация по `offset` (+100) до полного покрытия окна.
- Учитываются только **собственные** публикации сообщества.
- Закреплённые публикации (`is_pinned`) обрабатываются отдельно от хронологии:
  старый закреплённый пост НЕ считается «свежей» публикацией и не влияет на
  «Последнюю публикацию», но учитывается в ER-выборке как отдельный случай.
- Дедупликация постов по ключу `owner_id + post_id`.
- Пагинация завершается, когда все обычные собственные публикации последней
  полученной страницы опубликованы раньше `window_start`.

## Формула
Для каждого собственного поста с положительным количеством просмотров:

```
ER_поста = (лайки + комментарии + репосты) / просмотры
```

## Средний ER сообщества
Среднее арифметическое ER_поста по всем собственным публикациям сообщества
с корректным положительным количеством просмотров за окно:

```
ER_средний = Σ ER_поста / N, где N — число постов с views > 0
```

## Исключения из расчёта
- Посты с отсутствующими или нулевыми просмотрами НЕ включаются в расчёт
  и сохраняются отдельно с причиной `zero or missing views`.
- Сообщество без единого поста с views > 0 получает пустой средний ER.

## Хранение
- Промежуточный файл `posts_er.json`: на сообщество — `scored_posts` (с полем `er`)
  и `excluded_posts` (с полем `excluded_reason`).
- Итоговый лист «Посты за месяц» содержит обе группы.
- `verify_results.py` пересчитывает ER каждого scored-поста и сверяет со значением
  в файле (допуск 1e-4); расхождение = провал проверки.
