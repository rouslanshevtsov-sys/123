# Схема входного файла competitor_set.json

Навык работает **только** с сообществами из этого файла. Новые конкуренты не добавляются.

## Формат (пример — условные данные)

```json
{
  "generatedAt": "<дата формирования>",
  "competitors": [
    {
      "name": "<название сообщества>",
      "type": "direct | indirect | attention",
      "vk_url": "https://vk.com/<screen_name>"
    },
    {
      "name": "<название>",
      "type": "indirect",
      "group_id": -123456789
    }
  ]
}
```

Допускается и плоский массив `[{...}, {...}]` без обёртки `competitors`.

## Обязательные поля записи

| Поле | Требуется | Комментарий |
|---|---|---|
| `name` | да | Название конкурента |
| `type` | да | `direct` / `indirect` / `attention` |
| `vk_url` или `group_id`/`screen_name` | хотя бы одно | Ссылка на сообщество VK или идентификатор |
| `subscribers_hint` | нет | Подсказка; актуальное число берётся из API |

## Правила остановки при некорректном входе

- файл отсутствует → STOP «Входной файл не найден»;
- JSON не парсится → STOP с текстом ошибки парсинга;
- список пуст → STOP «нет записей конкурентов»;
- у записи нет ссылки/идентификатора → STOP с указанием индекса записи;
- недопустимый `type` → STOP с указанием допустимого набора.

Проверку выполняет `scripts/check_env.py`, результат — `competitors_resolved.json`.
