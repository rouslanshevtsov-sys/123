# Правила работы с изображениями

## Что скачиваем

- Только для **лучших постов** (ER ≥ бенчмарка сообщества).
- Все доступные изображения поста: `photo`, карточки `carousel`, обложки альбомов.
- Размер — вариант из `photo.sizes`, ближайший к ~1600 px по максимальной стороне,
  пропорции сохраняются (`best_photo_url` в `scripts/common.py`).

## Кэширование

- Файлы складываются в `media/images/<post_id>_<индекс>.jpg`.
- Существующий файл не перекачивается (кэш), пустой/битый файл перескачивается.
- Проверка сигнатуры содержимого (JPEG/PNG); HTML-заглушки отклоняются.

## Коллажи (`media/collages/<post_id>.jpg`)

| Число изображений | Компоновка |
|---|---|
| 1 | вставляется целиком (thumbnail ≤ 1600×1600) |
| 2 | рядом, один ряд (2 колонки) |
| 3–4 | сетка 2 × 2 |
| ≥ 5 | по 3 изображения в ряд (столбцы=3, ряды = ceil(n/3)) |

Ячейка 800×800, белый фон, изображения центрируются в ячейке без искажения пропорций.

## Встраивание в Excel

Коллаж (или единственное изображение) встраивается в строку листа «Лучшие посты»
в столбец «Изображения»; высота строки подстраивается; масштаб ≤ 300×240 px.

## Ошибки

Каждый сбой скачивания фиксируется в `unavailable.json` с конкретной причиной
(HTTP-код, тип исключения). Если у лучших постов ожидались изображения, но
не скачано ни одного — медиашлюз блокирует завершение (см. media-gate.md).
