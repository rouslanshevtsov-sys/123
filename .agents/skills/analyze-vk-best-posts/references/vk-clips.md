# Определение и обработка VK Клипов

## Подтверждение клипа

Для каждого видео-вложения проверяются **оба** уровня:

1. Внешний тип: `attachments[].type` — `clip` или `short_video` → клип.
2. Внутренний тип: `attachments[].video.type` — `short_video` / `clip` → клип.

Запрещено считать вложение обычным видео только потому, что внешний тип равен
`video`: внутренний тип решает. Если `attachments[].video.type` отсутствует —
вызывается `video.get` по `owner_id`, `id`, `access_key` (`videos=-X_Y[_key]`)
и проверяется `items[].type`.

## Просмотры для ER (обязательное правило)

**Если просмотры публикации и VK Клипа различаются, для расчёта ER и итогового
вывода используются только просмотры клипа** (`items[].count_views` из video.get).
Просмотры поста-контейнера как замена — запрещены; валидатор отклоняет такой запуск.
Число просмотров клипа фиксируется на момент сбора и выводится:
- лист «Клипы», колонка «Просмотры клипа»;
- листы «Лучшие посты»/«Проверенные посты», колонка «Просмотры для ER»
  (в датасете — флаг `views_source = "clip"`).

## Скачивание

Приоритет форматов из `video.get` → `item.files`:
`mp4_max/mp4_*/...` → HLS → DASH. Файлы — в `media/clips/<owner>_<id>.<ext>`.
Если поле `files` пустое: вызывается `video.getOembed` и используется публичный
VK-плеер; статус фиксируется как `failed:files_empty,oembed_player_only,...`
(расшифровка невозможна без потока — причина обязательна).

Обычные (неклиповые) видео **не скачиваются и не расшифровываются**.

## Статусы обработки

Допустимые финальные статусы подтверждённого клипа: `success`, `no_speech`,
либо `failed:<конкретная причина>` (только с явным согласием пользователя,
см. media-gate.md). Клип без статуса success/no_speech блокирует завершение этапа.
