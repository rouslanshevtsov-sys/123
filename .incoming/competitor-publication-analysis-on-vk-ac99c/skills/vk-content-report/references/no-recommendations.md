# Запрет на рекомендации и советы (все шаги вывода)

Итоговый отчёт — доказательное описание того, что уже произошло у конкурентов. Он не учит,
не планирует и не предлагает.

## Недопустимо ни в каком виде

- рекомендации и советы («рекомендуем», «советуем», «вам следует», «нужно делать»);
- контент-план, рубрикатор, идеи постов и публикаций, темы для своего канала;
- «что взять себе», «как повторить», «протестируйте», «внедрите», «планируйте»;
- выводы-инструкции, замаскированные под наблюдение («публиковать стоит по вторникам»).

## Формулировки, которые остаются в отчёте

- «В верхнем сегменте N из M постов содержат опрос» — наблюдение;
- «Читатели Community A спрашивают цену в комментариях поста X» — факт из комментариев;
- «Пост Y собрал ER ниже бенчмарка; чем это вызвано, данные не показывают» — честное
  отсутствие причины.

## Механическая проверка

`validate_report.py` сканирует текст на словарь `RECOMMENDATION_MARKERS` (включая слова
«контент-план», «идеи постов», «рекомендация») и падает с exit code 2 при любом совпадении.
Заголовки разделов тоже проверяются: нельзя назвать блок «Рекомендации».
