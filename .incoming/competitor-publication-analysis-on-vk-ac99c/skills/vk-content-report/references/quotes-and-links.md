# Цитаты и ссылки (шаги 6–8)

## Цитаты

1. Цитируется точный фрагмент публикации или комментария, без переноса смысла своими словами.
2. Длина цитаты — до 160 знаков; длинный текст обрезается с многоточием, смысл не меняется.
3. Кавычки «ёлочки»; орфография оригинала сохраняется, включая опечатки (без [sic]).
4. Каждая цитата обязана иметь ссылку на публикацию-источник рядом.
5. Цитата из комментария сопровождается указанием, что это комментарий, а не текст поста.

## Ссылки

1. Формат: `https://vk.com/wall-{owner_id}_{post_id}` для постов, `https://vk.com/clip-...`
   для VK Клипов. Другой формат ссылки запрещён.
2. Ссылка обязательна кликабельна: `<a href="...">post_id</a>`. Заглушки `href="#"` недопустимы.
3. Каждая ссылка ведёт на публикацию из датасета этого запуска (проверяется сверкой post_id).
4. Ссылки на изображения даются относительным путём внутри рабочей папки (например,
   `media/images/post_123.jpg`) плюс ссылка на сам пост.
5. Расшифровки VK Клипов: путь к файлу + ссылка на клип.
6. Вывод без хотя бы одной активной ссылки считается неподтверждённым и удаляется из отчёта.
