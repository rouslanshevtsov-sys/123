# Сегменты сильных и слабых публикаций (шаг 5)

## Правило отбора

1. Пул сегментации — все проверенные публикации обычного типа (VK Клипы вне пула,
   см. `clips-rules.md`).
2. Для каждого поста считается `rel_er_vs_benchmark = ER поста / бенчмарк своего сообщества`.
3. Верхний сегмент — 25% постов с наибольшим rel; нижний сегмент — 25% с наименьшим rel.
4. Числовые утверждения о разнице разрешены только при rel ≥ 2x (сильный) и rel ≤ 0.5x (слабый).
   Между 0.5x и 2x — «на уровне бенчмарка», сравнение числами запрещено.
5. Медиана сегмента считается по rel, приводится с указанием числа постов.

## Что фиксируется для каждой карточки сегмента

- тип публикации, дата, сообщество, уровень конкурента (прямой/косвенный/за внимание);
- лайки, комментарии, репосты, просмотры, ER, бенчмарк, rel;
- первая строка (цитата), CTA-тип, хук, типы аргументов, обещания, тон, число изображений;
- ссылки на доступные изображения;
- комментарии этого поста (если есть) — отдельным списком, не в содержательных сигналах.

## Сильный и слабый сегменты сравниваются только по наблюдениям

Формулировка вида «в верхнем сегменте чаще встречается X» требует указать доли:
«X из N постов верхнего сегмента против M из K постов нижнего». При малой выборке
(N < 5) добавляется оговорка о размере выборки, вывод остаётся наблюдением.
