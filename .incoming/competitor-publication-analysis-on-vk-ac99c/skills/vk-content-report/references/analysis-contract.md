# Контракт анализа (шаги 1–2 и общий маршрут)

Используется на шагах: входные данные, проверка метрик, сегментация.

## Что навык принимает и что делает

Навык работает **только с готовыми результатами предыдущего этапа** (анализ лучших публикаций).
Он не ищет конкурентов, не собирает посты заново и не дополняет выборку.

| Вход | Файл | Обязателен | Проверка |
|---|---|---|---|
| Датасет публикаций | `vk_posts_dataset.json` | да | поля, ER, ссылки, post_id |
| Комментарии | `comments.json` | да | связь с post_id датасета |
| XLSX выгрузка | `competitors_vk_report.xlsx` | да | лист «Лучшие», лист «Проверенные», сверка post_id |
| Происхождение | `provenance.json` | да | sha256 всех входов, множество проверенных post_id |
| Изображения | `media/images/` | по возможности | открываются ли файлы |
| Расшифровки VK Клипов | `media/transcripts/` | при наличии клипов | есть ли текст у каждого клипа |

## Порядок проверки перед анализом

1. Все обязательные файлы присутствуют и читаются как JSON/XLSX.
2. Каждый вход описан в `provenance.json`, хэш файла совпадает со записанным.
3. Множества `post_id`: XLSX ⊆ датасет; комментарии → только post_id из датасета;
   дубликатов post_id нет.
4. ER пересчитывается для каждого поста: `(лайки + комментарии + репосты) / просмотры`.
   Расхождение со значением датасета больше 0,5 п.п. — остановка.
5. Бенчмарк сообщества = средний ER всех постов этого сообщества за окно.
   Расхождение с заявленным больше 2% относительных — остановка.
6. `rel_er_vs_benchmark` = ER поста / бенчмарк **своего** сообщества.
7. Посты без просмотров (VK Клипы) получают отдельный статус: их ER считается по лайкам,
   комментариям и репостам, в общий бенчмарк сообщества они не входят.
8. Комментарии: ≥90% записей связаны с post_id датасета; минимум 5% постов имеют комментарии.

## Условие остановки

Если любой пункт не выполнен — работа останавливается, причина формулируется одной строкой
(файл, post_id или сообщество, ожидаемое и фактическое значение). Продолжать анализ
«приблизительно» запрещено.

## Сегментация

Верхний сегмент — 25% постов с наибольшим `rel_er_vs_benchmark`, нижний — 25% с наименьшим.
Правила — `references/segmentation.md`.

## Числовые сравнения

Сравнивать ER численно («в 3,4 раза выше») разрешено только при `rel >= 2x` или `rel <= 0.5x`.
В диапазоне 0,5–2 про разницу пишут словами: «на уровне бенчмарка», «немного выше бенчмарка».
