# Цепочка происхождения данных (provenance)

Гарантирует, что итоговый набор конкурентов выводим из подтверждённой карточки
бизнеса и реальных ответов VK API, без подмены и фабрикации данных.

## Звенья цепочки

```
business_context.json (status=confirmed)
   │ sha256 → context.py hash
   ▼
queries.json (поисковые запросы из карточки + дополнительно сгенерированные)
   ▼ groups.search count=1000 (build_pool.py)
pool_raw.json          {pool{gid→…}, queries_meta[{query,new_unique,pct_new,stop}]}
   ▼ groups.getById пакетами (vk_client.get_groups_batched)
details.json           сырые детали сообществ
   ▼ измеримые фильтры (filter_candidates.py)
shortlist.json + stage_filter.json (исключённые кандидаты с причинами)
   ▼ смысловая квалификация пакетам до 200 (языковая модель, компактные данные)
qualified.json         конкуренты с типом и полями квалификации
   ▼ wall.get окно 31×24 ч (collect_posts_er.py)
posts_er.json          scored_posts(er) + excluded_posts(причина)
   ▼ build_outputs.py
competitor_set.json + competitors.xlsx + run_manifest.json
```

## Обязательные элементы

1. **Хэш исходной карточки.** SHA-256 `business_context.json` записывается в
   `run_manifest.json.business_context_sha256` и
   `competitor_set.json.business_context.sha256`.
2. **Паспорт запуска** (`run_manifest.json`): временное окно, методы VK API,
   поисковые запросы, правила остановки расширения пула, параметры и ход
   пагинации, счётчики (пул/проверено/отобрано/исключено), ошибки и ограничения,
   фактическое число конкурентов и `shortfall`.
3. **Ссылки на входные файлы** в `competitor_set.json.provenance.inputs` —
   только имена файлов каталога вывода, без абсолютных путей.
4. **Промежуточные артефакты сохраняются** в каталоге вывода этапа и не
   перезаписываются задним числом после финализации.

## Проверка целостности (verify_results.py)

- Хэш карточки в JSON совпадает с фактическим (иначе — «разрыв цепочки», FAIL).
- Каждый конкурент имеет vk_url и непустые `sources_checked`.
- ER пересчитывается из posts_er.json; значения в JSON обязаны совпасть.
- Число строк Excel == число конкурентов JSON; каждая строка Excel имеет источник.
- Отсутствие секретов во всех артефактах.

## Запреты

- Никаких выдуманных сообществ, подписчиков, просмотров, ER.
- Никаких токенов, подписанных URL и абсолютных путей в артефактах.
- Нельзя менять критерии карточки ради достижения целевого числа.
