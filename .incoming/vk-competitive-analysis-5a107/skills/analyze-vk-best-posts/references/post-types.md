# Правила классификации форматов публикаций

Каждому посту назначается **ровно один** основной тип. Приоритет проверки:

| Тип | Условие |
|---|---|
| `Клип` | есть подтверждённый VK Клип (см. vk-clips.md) |
| `Видео` | есть обычное видео (не клип) |
| `Карусель` | есть вложение `carousel` **или** ≥ 2 изображений |
| `Картинка` | ровно 1 изображение |
| `Текстовый пост` | вложений нет (или только нетекстовые структурные без медиа) |

## Опрос

Ставится **только** при наличии вложения VK API `attachments[].type == "poll"`.
Упоминание опроса в тексте не считается.

## Розыгрыш

Ставится **только** при одновременном выполнении:
1. автор действительно проводит конкурс;
2. в тексте присутствуют механика, условия, сроки, упоминание победителя или приза.

Эвристика (`scripts/common.py`): ключевые слова (розыгрыш/конкурс/приз/победител*/разыгрыва*/giveaway/дарим бесплатно) И маркеры механики (подписк*/лайк/репост/комментари*/участн*/услов*/до <число>/итога*/рандом/счастливчик/выберем/определим/приз). Слово «конкурс» в нейтральном контексте («мы участвовали в конкурсе») розыгрышем не делает пост.

## Закреплённые публикации

- Пост с `is_pinned = true`, опубликованный **раньше начала окна**, исключается из выборки.
- Закреп внутри окна остаётся и обрабатывается как обычный пост.
- Число исключённых закреплений фиксируется в `raw_posts.json`
  (`excluded_pinned_before_window`).

## Репосты

Собственные публикации собираются через `wall.get?filter=owner`; дополнительно
проверяется `copy_history[0].from_id != owner_id` → чужие записи исключаются.
