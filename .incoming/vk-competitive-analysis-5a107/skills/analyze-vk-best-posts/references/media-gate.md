# Требования к медиапутям и правила блокирующего медиашлюза

## Требования к медиапутям

- Все пути в артефактах — **относительные** от рабочей директории запуска:
  `media/images/...`, `media/collages/...`, `media/clips/...`.
- Каждый путь, указанный в `vk_posts_dataset.json` (`image_files`, `collage_file`,
  `clips_processing[].file`), обязан существовать на момент проверки.
- Файл обязан быть ненулевым и иметь корректную сигнатуру (JPEG/PNG/MP4/webm).
- В XLSX встроенное изображение берётся из того же файла, что указан в датасете.
- Абсолютные пути конкретных машин в итоговые материалы не записываются.

## Блокирующий медиашлюз (`scripts/media_gate.py`)

Завершение этапа **заблокировано** (exit code 1), если хотя бы одно верно:

1. Для лучших постов ожидались изображения (`images` непустой), но не скачано ни одного.
2. Есть подтверждённый VK Клип без финального статуса `success` или `no_speech`
   (включая случай: посты типа «Клип» есть, а `clips_processing.json` пуст).
3. Медиапуть повреждён: файл из датасета отсутствует или пуст.
4. Отсутствуют обязательные зависимости (requests, PIL, openpyxl) или Whisper при
   наличии клипов, требующих расшифровки.
5. Выполняется деградированный запуск без явного согласия пользователя
   (флаг `--allow-degraded` выдаётся только после подтверждения пользователем).

## Дополнительные проверки валидатора (тот же скрипт)

- структура и открытие XLSX, 5 листов, точные колонки, freeze panes, фильтры, формат `0.00%`;
- синтаксис всех JSON;
- окно ровно 168 ч; отсутствие дублей post_id;
- ER по формуле; индивидуальные бенчмарки = среднее валидных ER; правило `ER >= бенчмарка`;
- комментарии связаны со строковым `post_id`;
- у поста «Клип» с доступными просмотрами клипа: `views_source == "clip"` и
  `views_for_er == clip_views_at_collection` — **подмена просмотрами поста отклоняется**;
- статус success без расшифровки — ошибка;
- секретов (vk1.a… токены, access_token) в итоговых материалах нет.

## Протокол запуска

```
python scripts/media_gate.py --workdir <DIR>            # штатная проверка
python scripts/media_gate.py --workdir <DIR> --allow-degraded   # только с согласия пользователя
```

Шлюз печатает `MEDIA GATE: PASS|FAIL` и список ошибок; FAIL возвращает ненулевой код,
что запрещает агенту объявлять этап завершённым.
