# Простой язык (шаги 6–8)

1. Пишем по-русски, короткими предложениями: одна мысль — одно предложение.
2. Термины объясняются при первом употреблении: «ER (вовлечённость: реакции делят на просмотры)».
3. Запрещены ИИ-штампы и канцелярит: «важно отметить», «в заключение хочется»,
   «в современном мире», «данная публикация демонстрирует», «комплексный подход»,
   «следует подчеркнуть». Проверка ищет их по словарю `AI_FILLER_MARKERS`.
4. Без оценок без данных: вместо «сильный креатив» — «собрал ER 2,9% при бенчмарке 0,7%».
5. Числа приводятся с источником: % долей, раза — только при rel ≥ 2x или ≤ 0.5x.
6. Названия сообществ и посты даются так, как они стоят в датасете, без «улучшения» имён.
7. Эмодзи в тексте отчёта не используются (кроме цитат из публикаций).
