# Точная структура HTML-отчёта (шаги 7–8)

Отчёт собирается скриптом `build_report.py` из шаблона `templates/report-template.html`.
Смысловые блоки идут **вертикально**, один под другим, без колоночной вёрстки.

## Порядок блоков (обязателен)

| id блока | Заголовок | Содержание |
|---|---|---|
| sec-scope | Масштаб анализа | таблица ≤8 строк: период, сообществ, постов, типов публикаций, комментариев; сноска об ограничениях выгрузки |
| sec-method | Метод | ER, бенчмарк, rel, правило сегментов, приоритет уровней конкурентов — формулами и словами |
| sec-top_posts | Сильные публикации | карточки верхних 25%: первая строка цитатой, метрики, наблюдение, ссылки |
| sec-er_signals | ER-сигналы | только наблюдения над цифрами, каждое со ссылкой |
| sec-cta_signals | CTA-сигналы | типы призывов с точными цитатами и post_id |
| sec-content_signals | Содержательные сигналы | хуки, аргументы, обещания, триггеры текста, тон |
| sec-comment_signals | Сигналы из комментариев | категории по сегментам + дословные цитаты комментариев со ссылками на пост |
| sec-clips | VK Клипы | отдельный блок: клипы, расшифровки, комментарии под клипами; обычные посты здесь запрещены |
| sec-low_posts | Слабые публикации | карточки нижних 25%, формат как у сильных |
| sec-conclusions | Выводы, подтверждённые данными | нумерованные выводы, каждый с уровнем опоры и доказательствами |
| sec-appendix | Приложения | что не удалось проверить, недоступные посты, служебные файлы |

## Жёсткие правила разметки

1. Каждый сигнал/вывод — элемент `.signal`, `.card`, `.clip-card` или `.conclusion`
   c внутренним списком `<ul class="evidence">` и минимум одной `a.evidence-link`.
2. Цитаты оборачиваются в `<span class="quote">`; источник файла — `<span class="src">`.
3. Атрибуты полезны для проверок: `data-confidence`, `data-level`, `data-causal`, `data-bucket`.
4. Никаких тегов `<script>`; таблицы — только для scope и сводок категорий.
5. Текст отчёта не содержит рекомендаций, советов, контент-плана и идей публикаций
   (`no-recommendations.md`).
