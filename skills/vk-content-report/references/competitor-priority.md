# Приоритизация типов конкурентов (шаги 5–6)

Порядок опоры для выводов фиксированный:

1. **Прямые конкуренты** (`group_type = direct`) — основной источник выводов.
2. **Косвенные конкуренты** (`indirect`) — подключаются, когда данных прямых недостаточно:
   меньше 10 проверенных постов прямых в сегменте либо признак встречается у прямых
   только в одном посте.
3. **Конкуренты за внимание** (`attention`) — подключаются последними, когда первых двух
   уровней не хватает; их данные используются для проверки гипотезы, сформулированной
   на прямых и косвенных.

## Правила использования

- Каждый вывод обязан показать уровень опоры: `competitor_level: direct | indirect | attention`
  и число постов этого уровня в доказательстве.
- Вывод, основанный только на «за внимание», помечается как дополнительный и не выносится
  в основные выводы без подтверждения хотя бы одним постом прямого конкурента.
- Смешивать уровни в одном числовом утверждении нельзя: «у прямых 4 из 10, у косвенных 3 из 7» —
  две отдельные фразы.
- Иерархия уровней не является данными: отсутствие признака у прямых конкурентов означает
  «в этой выборке не наблюдалось», а не «признак не работает».
