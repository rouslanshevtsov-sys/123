# Отдельный анализ VK Клипов (шаг 5)

VK Клипы никогда не смешиваются с обычными публикациями — ни в выборке, ни в выводах.

## Почему отдельно

1. У клипов нет просмотров ленты в том же смысле: их ER считают по лайкам+комментариям+репостам,
   знаменатель (просмотры клипа) фиксируется отдельно и не входит в бенчмарк обычных постов.
2. Алгоритм выдачи клипов показывает их холодной аудитории, поэтому вовлечение несопоставимо
   с постами в ленте подписчиков.

## Правила анализа

1. Пул клипов формируется по типу записи (`main_type = VK Клип` / `clips[].type = clip`).
2. Для каждого клипа обязана быть расшифровка (`media/transcripts/*.json`). Нет расшифровки —
   клип попадает в приложение со статусом `no_transcript` и не участвует в выводах.
3. Анализируются: тема первых секунд, обещание, подача, финальный CTA, реакция комментариев.
4. Выводы по клипам формулируются только внутри блока «VK Клипы»: нельзя писать
   «в верхнем сегменте» вместе про клип и обычный пост.
5. Ссылки на клипы используют формат `https://vk.com/clip-...`; в блоках обычных публикаций
   такие ссылки запрещены (проверяет `validate_report.py`).
6. Сравнение клип vs обычный пост допускается только как сопоставление порядков величин
   с явной оговоркой о разных алгоритмах показа, без вывода о превосходстве формата.
