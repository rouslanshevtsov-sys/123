# Формула ER, бенчмарки и выбор лучших постов

## Временное окно

- Единый момент старта фиксируется в `run_meta.json` (`run_started_at_msk`).
- Часовой пояс — **Europe/Moscow** (стабильный UTC+3).
- Окно: `[start − 168 ч, start)` ровно для всех сообществ одного запуска.

## Формула ER

```
ER = (лайки + комментарии + репосты) / просмотры
```

- Считается **только при просмотрах > 0**.
- Просмотры с нулём/отсутствием → статус поста `ER не рассчитан`; такой пост
  не входит в бенчмарк и не может быть «лучшим».
- **Просмотры для ER клипа:** если публикация содержит подтверждённый VK Клип,
  используется `count_views` **самого клипа** (video.get), а НЕ просмотров
  поста-контейнера. Правило обязательное: подмена просмотрами поста запрещена;
  валидатор `scripts/media_gate.py` отклоняет запуск при `views_source != "clip"`
  у клипа с доступными просмотрами клипа. Число просмотров клипа фиксируется
  на момент сбора и выводится в итоговой таблице (столбец «Просмотры для ER»,
  лист «Клипы»).

## Индивидуальный бенчмарк сообщества

```
бенчмарк = среднее арифметическое всех валидных ER постов этого сообщества за то же окно
```

- Посты без просмотров в расчёт не включаются.
- Бенчмарк хранится в `benchmarks.json` (ключ — owner_id) и дублируется в датасете.

## Выбор лучших постов

Пост считается лучшим, если:

```
ER поста >= бенчмарка сообщества
```

Равенство включает пост на уровне бенчмарка. Результат листа «Проверенные посты»:
`Лучший` / `Обычный` / `ER не рассчитан`.

## Пересчёт после медиаэтапа

После подтверждения клипов (video.get) ER клиповых постов пересчитывается по
просмотрам клипа и бенчмарки сообщества пересчитываются заново; только затем
формируются лучшие посты и изображения.
